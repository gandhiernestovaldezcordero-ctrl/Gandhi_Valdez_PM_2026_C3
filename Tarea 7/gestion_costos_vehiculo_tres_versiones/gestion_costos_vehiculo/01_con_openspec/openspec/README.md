# OpenSpec - Gestión de costos de vehículo

Esta carpeta documenta el desarrollo orientado por especificaciones para la versión 1.
El código ejecutable está en `../main.c`.

## Flujo de trabajo representado
1. Propuesta: definir el problema y el alcance.
2. Especificación: describir capacidades y escenarios verificables.
3. Diseño: decidir estructura de datos y persistencia en archivos.
4. Tareas: dividir la implementación en entregables.
5. Implementación: desarrollar y validar el código C.
